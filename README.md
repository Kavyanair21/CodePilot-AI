# 📌 Overview

CodePilot AI is an AI-powered intelligent code review platform that uses multiple specialized AI agents to analyze source code.

Instead of providing a simple code review, the application simulates a team of expert software engineers where each AI agent performs a dedicated task such as bug detection, security analysis, optimization suggestions, complexity evaluation, and code explanation.

The application also generates downloadable PDF reports and stores review history using SQLite.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Kavyanair21/CodePilot-AI.git
```

Move into the project

```bash
cd CodePilot-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=YOUR_API_KEY
```

Run the application

```bash
streamlit run app.py
```
